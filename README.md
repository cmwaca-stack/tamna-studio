# 제주의 모든것 (알뜰정보 제주살이)

> 제주에 **사는 사람**과 **찾아오는 사람**이 필요한 정보를, 귀엽게 움직이는 **3D 제주섬 지도** 위에서 한 번에 찾는 웹 서비스

- 배포 사이트: https://tamna-studio-wtoi.vercel.app
- GitHub: https://github.com/cmwaca-stack/tamna-studio
- 제주대 청년도약 부트캠프 1기 최종 프로젝트

## 왜 만들었나

제주 정보는 여기저기 흩어져 있어요. 관광은 관광 앱, 날씨는 기상청, 병원은 또 다른 곳, 쓰레기 배출·주유소·미세먼지 같은 생활 정보는 매번 새로 검색해야 합니다.
이 프로젝트는 공공데이터와 지도 서비스를 연결해 **제주 지도 위 한 곳**에 모읍니다.

### 3D 제주섬
- Three.js(React Three Fiber)로 만든 입체 제주섬. 산방산·성산일출봉·용두암·우도·비양도·마라도 등 지형지물, 돌고래·한치·갈치·낚시배·흑돼지·조랑말·해녀·비행기가 움직입니다.
- 기상청 예보에 맞춰 비·구름·바람이 나오고, 바람 나침반은 지도가 돌면 같이 돌아갑니다.
- 해녀 "혼저옵써", 산방산 "옵데강"처럼 가끔 제주어 말풍선이 뜹니다.

## 기술

- 화면: React 19, Vite, React Router, zustand, Three.js / React Three Fiber
- 서버: Vercel 서버리스 함수(`api/`) — 무료 플랜의 함수 12개 제한 때문에 한 함수에 여러 기능을 합쳤습니다
- 배포: GitHub에 push하면 Vercel이 자동 배포
- 키는 서버에만 둡니다(`VITE_`로 시작하는 값은 브라우저에 공개되는 값만)
- 검색으로 찾은 사진·주소는 미리 모아 `public/*.json`에 저장해서 호출 횟수를 아낍니다 (`scripts/` 참고)

## 폴더

```
api/        Vercel 서버 함수 (12개 이하 유지)
server/     공공 API·카카오 호출 함수
src/
  pages/        Home · Kit(주제별 정보) · DiscoverDetail · LinkPage · Guide · ...
  components/   Scene3D · Props(3D 소품) · TrafficMap · PlaceMap · AirQuality · LifeGuide ...
  data/         메뉴·링크·올레 코스 등 정적 데이터
  lib/          지형(terrain) · 날씨 · 풍향 · 카카오 지도 불러오기 ...
public/     로고·사진 목록(food-extra / spot-extra / market-images .json)
scripts/    사진·주소를 미리 찾아 json 으로 저장하는 스크립트
```

## 실행 방법

```bash
npm install
copy .env.example .env.local        # macOS/Linux: cp .env.example .env.local
# .env.local 에 값 채우기 (아래 표)
npm run dev                         # http://localhost:5173  (화면 + /api 동시 실행)
```

`.env.local` 을 고친 뒤에는 서버를 껐다 켜세요.

| 변수 | 설명 |
| --- | --- |
| `DATA_GO_KR_KEY` | 공공데이터포털 **Decoding 키** (TourAPI·기상청·에어코리아·한국전력 등 공용) |
| `KAKAO_REST_KEY` | 카카오 REST API 키 (서버 비밀 값: 장소·이미지 검색) |
| `VITE_KAKAO_JS_KEY` | 카카오 JavaScript 키 (지도 표시). 카카오 개발자 사이트 JavaScript SDK 도메인에 사이트 주소 등록 필요 |
| `ANTHROPIC_API_KEY` | AI 검색용 Claude 키 (서버 비밀 값) |
| `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY` | Supabase 공개용 값 (선택) |

## 배포

1. GitHub 저장소에 push (`.env.local` 은 올라가지 않습니다)
2. Vercel에서 저장소 연결, **Settings → Environment Variables** 에 위 변수 입력 (`VITE_` 변수는 "Config" 타입)
3. Redeploy — 환경변수는 재배포해야 적용됩니다
